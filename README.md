# Catálogo de Productos con Carrito

Breve: Una app en React que permite listar productos, buscarlos, filtrarlos y añadir al carrito.

##  Demo
- **Live**: *(pendiente deploy)*  
- **Repo**: este

##  Objetivos de aprendizaje
- React + manejo de estado (useState, useEffect)
- Filtrado y búsqueda
- Diseño con Tailwind CSS

##  Características
- Listado de productos con imagen, nombre, precio y botón "Agregar".
- Búsqueda por nombre.
- Filtrado por categoría y precio.
- Carrito: sumar/quitar productos y ver total.

##  Stack
- React, JavaScript
- Tailwind CSS
- Vite (si usaste)
